# Ashish — Personal Portfolio & Blog

GitHub Pages-ready static personal website for Ashish, M.Sc. Economics | Data Analytics.

## Deploy on GitHub Pages
1. Upload the contents of this folder to the root of `ashkaloia-lab.github.io`.
2. Go to Settings → Pages.
3. Select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save and wait a few minutes.

## Update content
- Main pages: edit the `.html` files in the root.
- Projects: add/edit files in `projects/`.
- Blog posts: add/edit files in `blog/` and add the post card to `blog.html`.
- CV: replace `cv/ashish-cv.pdf` with your updated CV, keeping the same filename.
- Styling: edit `assets/style.css`.
- Site behavior: edit `assets/site.js`.
